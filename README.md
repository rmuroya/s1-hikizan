# s1-hikizan
小一向けの引き算Webアプリ

- `index.html` … ひきざんクエスト（小一向け引き算）
- `oni.html` … おにから でんわ（4歳向け・鬼から電話がかかってくるアプリ）
  - 保護者が「だれに・理由・こわさの上限・自動で怖くなるか」を設定 → 着信画面 → 通話
  - 通話中は段階的に怖くなる（声が低く・画面が赤く・揺れる）。「ゆるす」で鬼が約束して電話を切る
  - セリフは各段階で「出だし・名前呼び・理由・締め」を複数パターンから毎回ランダムに組み立てる
  - 鬼の声は埋め込み済み（VOICEVOX：青山龍星 を加工）。端末の読み上げ機能は不要
  - 名前呼びは「ももか」「けいご」（くん／ちゃん）の音声を埋め込み。1ファイルで完結し、スマホのブラウザで開くだけで動く
