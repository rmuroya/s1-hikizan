# s1-hikizan
小一向けの引き算Webアプリ

- `index.html` … ひきざんクエスト（小一向け引き算）
- `oni.html` … おにから でんわ（4歳向け・鬼から電話がかかってくるアプリ）
  - 保護者が「名前・理由・こわさの上限・自動で怖くなるか」を設定 → 着信画面 → 通話
  - 通話中は段階的に怖くなる（声が低く・画面が赤く・揺れる）。「ゆるす」で鬼が約束して電話を切る
  - セリフは各段階で複数パターンから毎回ランダムに組み立てる
  - 鬼の声は埋め込み済み（VOICEVOX：青山龍星 を加工）。端末の読み上げ機能は不要
  - 名前呼び：`oni-voice/` によくある名前（約310種 × くん/ちゃん）の音声を用意。入力した名前の音声だけを読み込む
    - ファイル名は名前の1文字目のUnicode（例：`n-3051.json` = 「け」で始まる名前）
    - 名前の追加は `oni.html` 生成時の合成スクリプトで行う（VOICEVOXで「なまえくん。」「なまえくん！」を合成しピッチ加工）
  - `oni-voice/` は fetch で読むため、`file://` で開くと名前呼びは使えない（GitHub Pages などHTTP経由で開く）
